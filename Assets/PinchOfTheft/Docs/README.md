# Новая сцена

1. Выполните PinchOfTheft/Setup/Add Core To Scene. Повторный запуск не создаёт второй Core.
2. Добавьте Prefabs/Player/Player.prefab; поставьте персонажа на землю.
3. Добавьте Prefabs/CCTV/CCTV_Group.prefab; настройте номер и доступность на CCTVGroup.
4. Добавьте землю/стены, NavMeshSurface и запеките NavMesh для стандартного Humanoid.
5. При необходимости добавьте префабы головоломок и расположите их части. Сервисные ссылки подставятся при старте.
6. Выполните PinchOfTheft/Validate Scene и запустите Play Mode.

Базовая связка: шесть действий (Core, Player, CCTV_Group, земля, NavMeshSurface, Bake). Управление сохранено: мышь, Q/E внутри группы без цикличности, Tab и ПКМ; цифры вне панели кода отключены.

## Префабы

- Core/Core — контекст, камера-менеджер, InputLock, курсор, прицел, HUD, меню, Interactor, ClickToMove и EventSystem.
- Player/Player — капсула с агентом и маркером назначения.
- CCTV/CCTV_Group — четыре камеры с параметрами группы.
- Interaction/KeyPrompt — мировая подсказка E.
- Interaction/Interactable_Hold — заготовка удержания E; настройте onCompleted.
- Puzzle/CodePuzzle — щит, панель ввода и ТВ; внутренние ссылки связаны.
- Props/FallingBoard — стоящая/лежащая доска, точка подхода, попап.
- Puzzle/CurrentCircuit — цепь и её запуск.

## Совместимость

Имена InteractableSphere/SphereInteractor сохранены. Все UnityEvent-методы сохранены. Resolve вызывается однократно при инициализации, назначенные вручную ссылки имеет приоритет. Player регистрируется отдельно при появлении. ClickToMove сохраняет собственную маску и делает отдельный луч только по ПКМ, если маска отличается от AimProbe.

В test_Scene подключены сервисы к существующим объектам. По выбору пользователя прежняя служебная иерархия сохранена вместо замены на экземпляр Core.prefab. Модели и позиции сохранены.

Старые редакторские генераторы перенесены для истории; они содержат старые пути и могут пересоздавать сцену. Для работы используйте только новое меню PinchOfTheft.
