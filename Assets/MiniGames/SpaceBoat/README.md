# SpaceBoat — Unity 6000.6

Откройте `Scenes/SpaceBoat.unity` и нажмите Play. Камера, фон, корабль, строй и интерфейс создаются при запуске из явно назначенных локальных ресурсов. До запуска в сцене виден объект SpaceBoat с настройками игры.

## Управление и правила

- Корабль следует за горизонтальным положением мыши и остаётся внизу поля.
- Удержание левой кнопки мыши выпускает лазеры. Отпускание прекращает стрельбу.
- Один строй появляется целиком за верхним краем экрана и движется только вниз. Противники не стреляют.
- Один лазер уничтожает одного противника. Попадание проверяется на всём пути между физическими шагами, поэтому быстрый снаряд не пролетает сквозь врага.
- Столкновение противника с кораблём или достижение нижней границы — поражение.
- После поражения отпустите ЛКМ и нажмите её снова либо нажмите пробел, чтобы начать заново. Удержанная при поражении кнопка не перезапускает игру автоматически.
- Уничтожение всего строя — победа. Игра останавливается без меню и без закрытия приложения-хоста.
- Сверху отображается количество уничтоженных противников и их общее число.

## Настройка в инспекторе

Выберите корневой объект **SpaceBoat**, компонент **Space Boat Game**. Меняйте параметры до Play, чтобы сохранить их в сцене.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| Rows | 3 | Число рядов |
| Columns | 7 | Число противников в ряду |
| Enemy Speed | 0,55 | Скорость движения вниз |
| Enemy Width | 1,15 | Ширина врага; высота меняется пропорционально |
| Horizontal Gap | 1,3 | Промежуток между противниками в ряду |
| Vertical Gap | 0,6 | Промежуток между рядами |
| Spawn Offset | 0,5 | Отступ первого ряда над верхним краем экрана |
| Player Width | 1,1 | Ширина корабля с сохранением пропорций |
| Player Y | -6,8 | Высота корабля над нижней границей |
| Fire Interval | 0,2 | Секунд между выстрелами при удержании ЛКМ |
| Projectile Speed | 18 | Скорость лазера |
| Projectile Width | 0,1 | Ширина лазера с сохранением пропорций |
| Left Edge / Right Edge | -15,8 / 15,8 | Горизонтальные границы поля |
| Top Edge | 8,8 | Минимальная верхняя граница появления |
| Bottom Edge | -7,7 | Линия поражения при проходе врага вниз |

Строй центрируется между Left Edge и Right Edge. Если заданные промежутки не помещаются, расстояния между колонками уменьшаются. Не задавайте столько колонок или такую ширину врага, что сами спрайты перестанут помещаться в поле.

Первый ряд появляется выше максимума Top Edge и фактического верхнего края камеры. Остальные ряды размещаются над первым. Положительный Spawn Offset увеличивает задержку до появления врагов в кадре.

## Ресурсы и изоляция

| Используемый файл Art | Размер | Назначение |
| --- | --- | --- |
| chertolet (1).png | 110×90 | Корабль |
| jukkakaed (1).png | 160×140 | Противники |
| lazer (1).png | 10×40 | Лазер |
| fon (1).png | 3400×1920 | Статичный фон |

Маленькие версии без `(1)` сохранены, но не используются. Изображения не перерисовывались. Импорт: Sprite Single, Point, без mipmaps, без компрессии, Max Size 4096. Все масштабы равномерны по X и Y. Фон вписывается в окно с полями, без растягивания и прокрутки.

Всё находится в `Assets/MiniGames/SpaceBoat`: Scripts, Scenes, Materials, UI, Editor и Art. Своя сборка SpaceBoat и пространство имён SpaceBoat. Шрифт Arial скопирован из системного файла в UI; ссылки на Runner/Snake отсутствуют. Используется uGUI Text и локальный материал спрайтов. API Unity/uGUI и UnityCG — стандартные зависимости движка.

Используется Input System. В текущем проекте уже включён Input System Package (New), поэтому настройки менять не требуется. При переносе в другой проект нужен Active Input Handling = Input System Package (New) или Both. Новые слои, теги и изменения физики не нужны; глобальная гравитация и время не меняются. Сцену в Build Profiles автоматически не добавляли.

## Скрипты

- SpaceBoatGame — параметры, состояние игры, единственный строй, попадания и перезапуск.
- ShipController — мышь, горизонтальное движение, стрельба при удержании ЛКМ.
- Invader — движение вниз, контакт с кораблём и нижней границей.
- LaserProjectile — движение лазера и проверка его пути.
- SpaceBoatScene — сборка представления, камера, локальный шрифт и интерфейс.
- SpaceBoatVerification — редакторская проверка изоляции и проверка во временном проекте.

## Чек-лист

- [ ] Корабль следует за мышью только по горизонтали и не выходит за края.
- [ ] ЛКМ стреляет при удержании, отпускание прекращает выстрелы.
- [ ] Один строй появляется сверху за экраном; враги идут вниз без выстрелов.
- [ ] Все пропорции сохранены, используются большие версии изображений.
- [ ] Лазер уничтожает одного врага и увеличивает счёт.
- [ ] Поражение показывает перезапуск; победа останавливает игру.
- [ ] Tools → SpaceBoat → Validate Isolation проходит без ошибок.
- [ ] Перед каждым методом C# есть однострочный русский комментарий.
