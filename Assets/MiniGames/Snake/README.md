# Snake — Unity 6000.6

Корень: `Assets/MiniGames/Snake`. Откройте `Scenes/Snake.unity` и нажмите Play. Камера, фон, сегменты и интерфейс создаются при запуске из явно назначенных ресурсов сцены. До Play виден корневой объект Snake — это ожидаемо.

Используется пакет Input System. Подходит Active Input Handling = Input System Package (New) или Both; в текущем проекте новый ввод уже включён. Настройки проекта не менялись. Слои, теги, физику и Build Profiles менять не нужно.

## Правила

- Движение WASD; начальная длина — голова и два круглых сегмента. Змейка начинает движение вправо.
- Разворот на 180 градусов запрещён; один поворот между шагами.
- Все три символа появляются сразу в разных свободных клетках. Порядок сбора — слева направо в исходном пароле.
- Правильный символ добавляет сегмент и открывает ячейку справа.
- Ошибка закрывает все ячейки, сохраняет длину и заново размещает все три символа вне тела змейки.
- Граница или столкновение с собой — поражение. Вход в клетку хвоста, освобождаемую в этот шаг, разрешён.
- После поражения пробел или клик начинает игру заново с длиной 3.
- После третьего правильного символа движение и анимация останавливаются; приложение-хост не закрывается.
- Если после многократных ошибок на поле не осталось трёх свободных клеток для символов, игра заканчивается поражением.

## Настройки на объекте Snake

| Компонент | Параметр | Значение |
| --- | --- | --- |
| Snake Game | Columns / Rows | 29 / 20 |
| Snake Game | Step Interval | 0,16 секунды на клетку; меньше — быстрее |
| Snake View | Field Top Left | (-15,6; 8,6), верхний левый угол поля |
| Snake View | Cell Size | 0,8, размер сегмента и клетки |

Сетка невидимая; поле сдвинуто вверх на одну клетку, снизу добавлен дополнительный ряд. Левый верхний участок 3×3 смертелен, символы в нём не появляются. При изменении количества клеток или их размера оставляйте поле внутри рисунка. Масштаб всех спрайтов равномерный; фон при другом формате окна показывается с полями, без растягивания.

## Структура

- Scripts/SnakeBoard.cs — независимая от Unity клеточная модель.
- Scripts/SnakeGame.cs — ввод, таймер, перезапуск.
- Scripts/SnakeView.cs — спрайты, анимация, ячейки и сообщения.
- Scripts/SnakeScene.cs — создание камеры, фона и интерфейса.
- Scenes/Snake.unity — отдельная сцена со всеми назначенными ресурсами.
- Editor/SnakeVerification.cs — проверка изоляции и запуска временного тестового проекта.
- .Checks~ — воспроизводимые проверки модели; Unity игнорирует эту папку.

## Проверка

Tools → Snake → Validate Isolation проверяет отсутствие прямых ссылок на ассеты вне Snake. Проверки модели: `dotnet run --project .Checks~/ModelChecks.csproj` (рабочие каталоги .NET направлять внутрь .Checks~).

- [ ] Голова анимирована, тело круглое, начальная длина 3.
- [ ] Пропорции изображений сохраняются при изменении окна.
- [ ] Все символы видны сразу и размещаются вне тела.
- [ ] Правильный сбор увеличивает длину и открывает ячейку.
- [ ] Ошибка сбрасывает пароль и символы, сохраняя длину.
- [ ] Поражение предлагает перезапуск; победа останавливает игру.
- [ ] Ресурсы локальны, Runner и настройки проекта не изменены.
- [ ] Перед каждым методом стоит однострочный русский комментарий.

Результаты автоматических проверок — в Verification.txt. Графический вид и реальный ввод WASD нужно проверить вручную в Game View.
